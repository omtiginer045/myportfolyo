# Ömer Coşkun — Kişisel Portfolyo

Ömer Coşkun'un kişisel portfolyo ve CV sitesi.

Canlı: https://myportfolyo-w5za.vercel.app

## Teknolojiler

Vite + React 19, düz CSS, Vitest

## Komutlar

```bash
npm install
npm run dev
npm test
npm run build
```

İçerik `src/data/` altındaki dosyalardan düzenlenir.

## Yayın

Vercel, `main` dalı.
